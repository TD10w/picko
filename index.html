How it works

One photo. One small decision.

  1. ← Set aside Keep →

    1Swipe

    Right keeps it. Left sets it aside. No menus, no folders. If a photo makes you smile, stay a while.

  2. 3 set aside · 7.1 MB

    2Review before deleting

    Everything you set aside waits in Review. Look again, change your mind, keep anything you like.

  3. Delete 3 · 7.1 MB Then iOS asks you once more

    3Confirm

    Only now does anything leave. Deleted items go to Recently Deleted in Photos, where you can still bring them back for 30 days.
